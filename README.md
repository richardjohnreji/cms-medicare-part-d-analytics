# CMS Medicare Part D Analytics

## Project Overview

This repository contains an end-to-end Healthcare Analytics project using the CMS Medicare Part D Prescribers dataset.

The goal of this project is to analyze prescription patterns across healthcare providers, identify prescribing trends, evaluate drug utilization, and generate actionable business insights through SQL, Python, and Power BI.

This project is designed as a professional portfolio project that mirrors how healthcare analytics teams work in real organizations.

---

# Dataset

Source

Centers for Medicare & Medicaid Services (CMS)

Dataset

Medicare Part D Prescribers by Provider and Drug

The dataset contains prescription information submitted under the Medicare Part D program for providers across the United States.
